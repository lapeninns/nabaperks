- **04#54** (panel instructional copy) — a product/copy decision. Trimming five
  panel descriptions risks removing operator-facing procedure; flagged, not guessed.
- **04#60 / 04#26 sticky header** — the table's scroll container is
  `surface-card overflow-hidden` wrapping an `overflow-x-auto` region, so a sticky
  `thead` has no scrollport to stick to. Fixing it is a layout change that needs
  browser proof.

  that need a real browser.
- **04#60 sorting** — a large DataTable API addition consumed live by eight admin

  lanes). Where a fix needed a shared component's behaviour — the disclosure's
  dashed tone (04#53) — it was pinned from the admin call site instead.

## Bug found that the audit missed

`getAdminQrCodes` embedded `merchants(business_name)` while `qr_codes.merchant_id`
is `NOT NULL`, and `getAdminAuditLogs` embeds a nullable merchant. When adding
venue filtering, an unconditional `merchants!inner` on the audit query would have
silently dropped every audit row with no merchant — most of the security actions.
The audit reader therefore switches its embed to `!inner` only when a venue
fragment is supplied.
