## Bug found that the audit did not name

`/app/activity` "Load more" was a dead control at the ceiling, not merely an
unannounced one. `loadMoreHref` sets `limit + 50` without bound while
`parseActivityLimit` clamps at 250, so from the fifth press onward the button
navigated to a URL that returned exactly the rows already on screen — a
spinner, a scroll jump, and no new content. Fixed under 03#52.
