# Archived Agent Guidance

This directory preserves historical repository agent instructions as reference
documentation.

The archived files are intentionally named `AGENTS.reference.md` so they are
not automatically applied as agent instructions. Their original relative paths
are preserved beneath this directory.

Factory Missions should use native planning, orchestration, workers, and
risk-based validation. Repository-specific guidance can be selectively restored
later if it is needed.

Restoring any archived file under the exact name `AGENTS.md` reactivates its
instructions for that directory and all of its descendants.
