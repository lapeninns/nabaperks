Circular rubber-stamp mark — the venue's identity and every state seal in one component.

```jsx
<VenueMark initials="OC" caption="OLD CROWN" />                       // venue logo
<VenueMark initials="✱" caption="Nº RW-8821" color="var(--w-leaf)" /> // reward
<VenueMark initials="✓" caption="12 JUN 2026" color="var(--w-leaf)" /> // redeemed
```

Always slightly rotated (looks hand-stamped). Caption auto-hides below 58px. Use ink colour to carry state: accent = identity, leaf = success, ink-soft = pending.
