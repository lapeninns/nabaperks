The mystery reward seal — the payoff moment at 3 visits. Gold disc, "?" glyph, broken by the customer.

```jsx
<Seal mode="Hold" onBroken={() => setStep("revealed")} />
```

`Hold` (default) requires a ~850ms press with a progress ring — the recommended ritual. `Tap` is instant. Wiggle while held, shake on break; pair the reveal that follows with `CelebrationBits type="Burst"`.
