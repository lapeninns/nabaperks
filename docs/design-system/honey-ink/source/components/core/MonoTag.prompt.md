Uppercase mono chrome: `MonoTag` is the pill chip ("STAMPED", "Browser first"); `MonoLine` is the bare meta line (eyebrows, card numbers, footnotes).

```jsx
<MonoTag tone="accent">Stamped</MonoTag>
<MonoLine>The Old Crown · Bristol</MonoLine>
```

Tones: `plain` (default, quiet), `accent` (celebration moments), `ink` (saved/ready states). All receipt-style metadata goes through these — never style mono text by hand.
