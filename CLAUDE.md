# Claude Agent Guide

Use `AGENTS.md` as the primary repo entrypoint.

This file exists so Claude-based agents land on the same current governance
spine as Codex and other agents. It is intentionally short to avoid drift.

## Current Governance Files

- `AGENTS.md` - repo stack, working rules, and governance routing.
- `Instructions_MircroSpecsCreation.md` - how to author future Micro-Specs.
- `Instructions_tdd.md` - implementation workflow when an active spec and its
  required harness exist.
- `micro-specs/README.md` - governance index, lifecycle policy, and current
  verification gates.
- `micro-specs/GLOBAL_CONTEXT.md` - reusable project constraints.
- `DESIGN.md` - Wet Ink design-system source of truth.

There are currently no active feature Micro-Specs checked in. Use only current
checked-in files and current package scripts as implementation input.
